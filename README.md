# 音乐融合工坊（MixLab）

本地运行的 AI 音乐混音工具，面向 vlog 创作者。Spotify 风格深色界面，
三个独立功能页（顶部导航切换）：

- **拼接**：两首歌无缝衔接，可视化时间线拖拽切点，节拍/调性自动对齐
- **融合**：两首歌合成一首，支持 A 人声 + B 伴奏、A 为主 B 为辅、均衡混合
- **分离**：AI 把一首歌拆成人声、鼓、贝斯、吉他、钢琴、其他（含弦乐）

所有 AI 处理都在本机 GPU 完成，不上传任何数据。

## 快速开始

1. 双击 `启动工具.bat`
2. 浏览器自动打开 `http://localhost:8000`
3. 导入两首歌，选择模式，点击「开始处理」

## 模式说明

### 拼接

- A 的前段 + B 的后段，切点可手动调整
- 自动做节拍对齐（轻微变速、保持音高）和调性对齐（轻微移调）
- 交叉淡化让过渡自然，统一响度后导出

### 融合

- **A 人声 + B 伴奏**：AI 分离两首歌后重组（最耗时，约 2-6 分钟）
- **A 为主 · B 为辅**：以 A 为骨架，融入 B 的鼓点或整曲
- **均衡混合**：两首等量混合

### 分离

- 上传一首歌，AI 分离为 6 个音轨：人声、鼓、贝斯、吉他、钢琴、其他
- 每个音轨可独立试听、下载，也可打包 ZIP 一次下载
- 注：开源模型最细只到 6 轨，弦乐归入「其他（含弦乐）」

## 技术栈

- 后端：FastAPI + Demucs 4.1 (htdemucs_6s) + librosa + ffmpeg（imageio-ffmpeg 自带）
- 前端：原生 HTML/CSS/JS，Spotify 风格深色界面，三页 SPA + 顶部导航
- 分离模型运行在本机 GPU（NVIDIA 3060 实测：24 秒音频约 10 秒完成）

## 模型来源

六轨分离权重（htdemucs_6s，55MB）来自 ModelScope 的
[pengzhendong/uvr-demucs](https://modelscope.cn/models/pengzhendong/uvr-demucs)
镜像仓库，已下载到 `data/models/demucs_6s/`，离线可用，无需再联网。

```
│  ├─ results/       # 导出成品

```
